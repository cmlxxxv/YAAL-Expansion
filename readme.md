# Yet Another Altium Libary Expansion

Дополнение к основной библиотеке [YAAL](https://github.com/cmlxxxv/YAAL)

## Ответы на вопросы

**В: Зачем?**  
О: Некоторые элементы необходимые для проектирования печатной платы очень плохо подходят для интеграции из в базу данных. Примером таких компонентов могут быть различные установочные изделия, которые не нужно добавлять в схему, но под них нужно сделать разметку крепёжных отверстий. В случае библиотеки построеной на базе данных у каждого элемента обязаны быть как УГО так и посадочное место. Плюс ко всему движок AD относится к компонентам из БД как к типу Standard, что на уровне движка подразумевает синхронизацию элементов между ПП и схемой. Соответственно если Вы добавляете элемент только в ПП, то при каждой передачи изменений из схемы движок будет пытаться удалить его. Данный "костыль" позволит обойти этот момент.

**В: Допустим. Как это поставить?**  
О: Установка как и для других библиотек. Вкладка *Data Managment* - *File-based Libraries* и внизу будет кнопка *Install*. Устанавливать необходимо файл *.PcbLib*. Для отображения элементов во вкладке *Components* необходимо включить пункт *Footpints*.
